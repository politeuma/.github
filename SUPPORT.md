# Support

- **Bug reports and feature requests:** open an issue in the relevant
  repository. Check the [glossary](profile/glossary.md) first — many
  questions about terms are answered there.
- **Legal content corrections** (a grounding cites the wrong article, a law
  changed, a review date passed): open a grounding proposal in
  [law-map](https://github.com/politeuma/law-map) using the
  *Grounding proposal* template. You do not need to write YAML — a plain
  description with a link to the source is enough.
- **Security issues:** do not open a public issue. See
  [SECURITY.md](SECURITY.md).
- **General questions:** open a discussion or issue in the repository that
  fits best; maintainers answer on a best-effort basis (this is a small
  team — see the bus-factor note below).

Response times are best-effort. There is currently a single maintainer;
if maintainership changes or lapses, the continuity plan in each
repository's GOVERNANCE file (where present) applies.
